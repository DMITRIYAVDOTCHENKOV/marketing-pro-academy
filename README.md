# Маркетинг PRO — версия 9.3

Версия 9.3 расширяет пользовательский путь без сокращения учебной базы: страницы
направлений открывают единое учебное ядро напрямую, без iframe и двойной
прокрутки. Навигация стала иерархической, а типографика — компактнее.

В версии 9.1 добавлены расширенные модули по аукционам GSP/VCG, цене и ценности
целей, A/B-экспериментам, корректировкам, Wordstat и семантическому ядру,
операторам, стоп-словам и автотаргетингу. Поиск предлагает подсказки по основным темам.

Локальная многостраничная академия по Яндекс Директу, РСЯ, Яндекс Метрике,
SEO, медиапланированию, формулам, ведению и контролю проектов.

## Быстрый запуск

Откройте `index.html` или запустите локальный сервер:

- Windows: `start_windows.bat`
- macOS: `start_mac.command`
- Linux: `start_linux.sh`

После запуска откройте `http://127.0.0.1:8765/`.

## Сохранение данных

При обычном открытии HTML данные сохраняются в браузере. При запуске через
`server.py` доступно файловое сохранение в `data/user_state.json`.

На GitHub Pages в Chrome/Edge можно нажать «Выбрать папку на ПК». После явного
разрешения браузера платформа сохраняет локальную копию
`marketing-pro-user-state.json` только в выбранную пользователем папку. GitHub
не получает содержимое этого файла.

Файл `data/user_state.json` исключён из Git, поскольку может содержать личные
заметки и сведения о проектах. Для нового развёртывания используйте
`data/user_state.example.json`.

## GitHub Pages

Проект является статическим и может публиковаться через GitHub Pages.
На GitHub откройте `Settings → Pages`, выберите `Deploy from a branch`, ветку
`main` и каталог `/ (root)`.

На GitHub Pages работает браузерное сохранение. Серверное файловое сохранение
через `server.py` требует отдельного хостинга и на GitHub Pages недоступно.

## Конфиденциальность

Не добавляйте в публичный репозиторий реальные клиентские данные, телефоны,
email, CRM-выгрузки, рекламные токены и заполненный `data/user_state.json`.
